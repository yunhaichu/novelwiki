## 当前核心定位

未来蓝星科学家陆知远获得五级文明遗物“星种”，看见真实宇宙文明坐标。为获得寿命、身体承载力和跨文明探索能力，他选择先进入修真型恒星系文明“玄衡道庭”，从青岚星底层开始寻找生命跃迁路径。

第一卷目标：陆知远在青岚星活下来，确认灵构体系真实有效，完成定脉，并获得星衡院分院外围录事身份。

## 硬规则摘要

1. 第一卷不展开五级文明真相。
2. 第一卷不让主角乘坐星舟。
3. 第一卷只完成定脉，不进入灵核。
4. 星衡院分院是基层边缘机构，不是高等圣地。
5. 星种不是人格化系统，不发任务，不给奖励。
6. 主角不能靠倒卖、现代武器或蓝星医疗碾压青岚星。
7. 主角第一卷的胜利是获得入口，不是获得胜局。
